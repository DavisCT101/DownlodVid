# NovaPlay

NovaPlay is an anti-scraped media search, streaming, and downloader platform built with Node.js, Express, and Tailwind CSS.

## Features
- Search YouTube tracks by name or paste direct YouTube URLs.
- Native anti-scraping guard & express rate-limiting middleware.
- Responsive YouTube embedded player (`youtube-nocookie.com`).
- High-speed MP3 audio & MP4 video conversion hand-off (360p through 4K).
- Clean solid dark design without gradient slop or emojis (Font Awesome 6 icons throughout).

## Setup & Execution

```bash
# 1. Install dependencies
npm install

# 2. Start the server
npm start
